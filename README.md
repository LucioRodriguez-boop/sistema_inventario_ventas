El siguiente proyecto hace referencia al desarrollo del siguiente sistema: Sistema de inventario y Ventas.

Este sistema tendrá los módulos de compra y ventas, y por ello entonces se podrá administrar el invetario por medio de un control de invetario. Dicha gestión de inventario administrará la entrada de producto (compras), salidas de productos (ventas) y se podrán generar reportes de inventario por Stock

Sistema de desarrollo por el aula 3DS.
